# سربرگ نامه داخلی شرکت ۱۰۰۳

- `Inner-A4.mrt` و `Inner-A5.mrt` منبع سربرگ چاپ داخلی هستند.
- تصویر سربرگ از طرح موجود و تأییدشدهٔ هومپا در قالب صادرهٔ همان شرکت گرفته شده است؛ قالب داخلی مستقل است و هیچ اتصال دیتابیس، امضا، مهر یا عبارت پایانی ندارد.
- سرویس تصویر `Watermark.ImageBytes` را می‌خواند و **هندسهٔ سه کادر شماره/تاریخ/پیوست** را از خود قالب:
  `Text10` = `{DataSource1.LetterNumber}`، `Text11` = `{DataSource1.DateShams}`، `Text12` = `{DataSource1.Peyvast}`.
  موتور Stimulsoft یا اسکریپت قالب اجرا نمی‌شود؛ فقط XML خوانده می‌شود.
- مختصات این کادرها **مطلق صفحه** است (چون `Margins` قالب صفر است) و عیناً همان کادرهای قالب صادرهٔ ۱۰۰۳:
  A4 → y = ۰٫۸۲۳۳ / ۱٫۰۷۳۳ / ۱٫۳۳۳۳ اینچ (۵۹٫۲۸ / ۷۷٫۲۸ / ۹۶pt) و A5 → ۰٫۵۶۲۸ / ۰٫۷۳۹۶ / ۰٫۹۲۳۴ اینچ.
  مرکز عمودی‌شان روی مرکز برچسب‌های چاپ‌شدهٔ سربرگ می‌افتد: ۶۶٫۵ / ۸۴٫۵ / ۱۰۳٫۲pt در A4.
  اگر این کادرها را جابه‌جا کردید، مقادیر چاپی هم همان‌جا می‌نشینند (نسخهٔ پشتیبان در کد:
  `HomepaLetterheadLayout.AbsoluteNumber/Date/Attachment`).
- تصویر جاسازی‌شده همان **طرح تأییدشدهٔ سربرگ صادره** است (۲۴۸۱×۳۵۰۸ پیکسل، ۳۰۰dpi) تا دو چاپ یکدست بمانند.
- فونت/متن و هامش توسط QuestPDF ساخته می‌شوند. پس‌زمینه روی تمام صفحات تکرار می‌شود.
- مقدار پیوست (`دارد` / `ندارد`) در هدر مانند شماره و تاریخ تراز راست است و در یک خط ثابت می‌ماند (بدون شکست خط/بزرگ شدن عمودی); سربرگ روی صفحات بعدی تکرار می‌شود.
- برای تغییر طرح داخلی، تصویر جاسازی‌شدهٔ همین قالب‌ها را تغییر دهید. در صورت جابه‌جایی نوار شماره/تاریخ/پیوست، مختصات هدر نیز باید هماهنگ شود.
- الگوی `Reports/**/*.mrt` در پروژه هر دو فایل را با Build/Publish کپی می‌کند.
