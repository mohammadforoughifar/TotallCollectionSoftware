# اقلام بیجک: انتخاب از انبار + ورود دستی

قراردادهای منبع `test_goods_issue_items.py` رفتار فرم «بیجک» (حوالهٔ بدون قیمت) را
نگه می‌دارند: هر سطر می‌تواند **از فهرست کالاهای انبار** انتخاب شود یا **نام آزاد
دستی** داشته باشد.

اجرا:

```
cd inventory
python3 tests/GoodsIssueItems/test_goods_issue_items.py -v
```

این تست‌ها قرارداد متنی و یک آینهٔ منطقی‌اند و جایگزین بیلد Razor، تست زندهٔ API و
تست مرورگر نیستند (SDK دات‌نت در این محیط موجود نیست). پیش از انتشار:
`dotnet build` و یک تست دستی (ساخت بیجک با یک سطر انبار و یک سطر دستی، ویرایش نام
سطر انبار، چاپ) لازم است.

مستند رفتاری: `docs/GOODS-ISSUE-ITEMS-FA.md`.
