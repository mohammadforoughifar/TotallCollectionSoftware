# تست ستون زمان ایجاد نامه‌ها

از پوشهٔ `inventory` اجرا کنید:

```sh
dotnet run --project tests/LetterCreatedAt/LetterCreatedAt.csproj
```

آزمون با `AppDbContext` واقعی و SQLite در حافظه، خطای خواندن رکورد کامل نامهٔ داخلی را بازتولید می‌کند. نصب تازه، نصب قدیمی با ترکیبی از ستون‌های موجود و غایب، ثبت نامهٔ جدید، اجرای دوباره، جدول وارده‌ای که دیرتر ساخته می‌شود، rollback تراکنش و آرشیو با بیش از ۵۰٬۰۰۰ نامه بررسی می‌شوند. بخش SQL Server، کوئری EF، اسکریپت مایگریشن و snapshot را بدون اتصال به سرور بررسی می‌کند. این تست به تنظیم اتصال یا دادهٔ نصب کاربر دست نمی‌زند.
