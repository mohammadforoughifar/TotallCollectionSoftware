# تست‌های ماژول RemoteDesktop

```bash
node --test inventory/tests/RemoteDesktop/*.test.cjs
```

پوشش فعلی:
- ثبت سرویس‌ها/هاب‌ها و ماژول RBAC
- idempotent بودن schema
- جریان رضایت و حسابرسی
- اتصال صفحات و اسکریپت viewer
- نرمال‌سازی مختصات موس و جلوگیری از ورودی در حالت فقط مشاهده
- پروژه ایجنت و کلید دستگاه

تست واقعی تصویر/ورودی باید روی ویندوز و با یک دستگاه آزمایشی انجام شود.
