# پیش‌نمایش چاپ فروشگاهی

این آزمون‌ها قرارداد مسیرهای چاپ و رفتار رابط پیش‌نمایش را جدا از اجرای برنامه بررسی می‌کنند:

```bash
python3 -m unittest discover -s tests/ShopPrintPreview -p 'test*.py'
CHROME_BIN=/path/to/chromium NODE_PATH=/path/to/node_modules node --test tests/ShopPrintPreview/preview.test.cjs
```

برای آزمون دوم بستهٔ `puppeteer-core` لازم است. آزمون مرورگر از فایل‌های واقعی JS، CSS و PDF.js استفاده می‌کند، ولی برنامهٔ Blazor، API، پایگاه داده یا چاپگر واقعی را اجرا نمی‌کند. موارد آزمون شامل جلوگیری از چاپ خودکار، کلیک چاپ و F4، بستن با Esc، نسخهٔ جدا از فرم، کنترل‌های زنده، کاغذ A5 و نمای موبایل، QR و راهنما، چاپ مجازی گزارش، و مسیر جایگزین چاپ PDF است. تعداد و اندازهٔ واقعی صفحه‌های خروجی PDF چندصفحه‌ای افقی نیز با چاپ مجازی Chromium کنترل می‌شود؛ لغو، پاک‌سازی، خطای صفحه و اندازه‌های متفاوت صفحات نیز بررسی می‌شوند.

پس از build واقعی، با یک شرکت/فاکتور واقعی و مرورگر Edge یا Chrome روی ویندوز هم خرید، فروش، بیجک، تعمیرات، گزارش‌ها، سند تسویه، فهرست کالا و کارت ویزیت را بازبینی و چاپ آزمایشی کنید. «ثبت و چاپ» ابتدا سند را ثبت می‌کند؛ بستن پیش‌نمایش ثبت را لغو نمی‌کند. نمایش صفحه‌بندی دقیق نهایی به تنظیمات چاپ مرورگر بستگی دارد. در مرورگری که امکان چاپ PDF اصلی را ندارد، نسخهٔ جایگزین برای چاپ با رندر صفحه‌های PDF ساخته می‌شود. این مسیر، برای جلوگیری از خالی شدن حافظه یا چاپ بی‌کیفیت، فایل‌های بسیار بزرگ یا با اندازهٔ صفحه‌های متفاوت را چاپ نمی‌کند و برای آن‌ها دریافت و چاپ PDF اصلی را پیشنهاد می‌دهد.

## رفع پیش‌نمایش سفید (۲۰۲۶-۱۱-۰۹)

علت، قانون سراسری `body * { visibility:hidden !important }` در `letters.css` بود.
این فایل در صفحه اصلی بارگذاری می‌شود و مسیر `openElement` تمام استایل‌ها را به
سند مستقل کپی می‌کند. بازتاب قواعد چاپ برای نمایش روی صفحه نیز این قانون را اعمال
می‌کرد؛ بنابراین هم پیش‌نمایش و هم PDF چاپی گزارش خالی بودند. مسیرهای HTML مستقل،
PDF و کارت که استایل مستقل یا قانون نمایش مجدد داشتند لزوماً درگیر نبودند.

اصلاح فقط در `shop-print-preview.js` اعمال می‌شود: هنگام کپی استایل‌ها به سند
مستقل فروشگاهی، لینک `css/letters.css` کپی نمی‌شود. خود فایل دبیرخانه، نسخه URL
و رفتار اصلی چاپ آن بدون تغییر مانده‌اند؛ تغییر قبلی در آن فایل برگشت داده شد.
نسخه URL اسکریپت اختصاصی پیش‌نمایش فروشگاهی افزایش یافت.

آزمون مرورگر اکنون `letters.css` واقعی را مانند صفحه اصلی بارگذاری می‌کند. پیش از
اصلاح، دو آزمون گزارش با محتوای مخفی و PDF بدون متن شکست خوردند؛ پس از اصلاح هر
۱۹ آزمون Chromium موفق بودند، از جمله چاپ PDF گزارش، کارت/QR، راهنما، A5 و
حفظ جداسازی چاپ نامه. این بررسی جای تست نصب واقعی Blazor و چاپگر ویندوز را نمی‌گیرد.
