# بررسی ستون‌های حساب ورود (`Users`)

از پوشهٔ `inventory` اجرا کنید: `dotnet run --project tests/CoreUserColumns/CoreUserColumns.csproj`.

آزمون از `AppDbContext` واقعی و یک دیتابیس SQLite در حافظه برای هر سناریو استفاده می‌کند: فقدان هر دو ستون، وجود فقط یکی و وجود هر دو. خواندن موجودیت EF، نگه‌داری مقدارهای موجود، پیش‌فرض رکوردهای قدیمی، نوشتن رکورد جدید، اجرای تکراری و rollback تراکنش بررسی می‌شود. برای SQL Server نیز کوئری، ثبت مایگریشن، اسکریپت ارتقا و نگاشت snapshot بررسی می‌شوند؛ این آزمون به SQL Server متصل نمی‌شود و اطلاعات نصب کاربر را تغییر نمی‌دهد.
