## شکاف‌های ویندوزی (تست دستی لازم)

- ACL با `icacls` و هویت `IIS AppPool\<pool>`.
- توقف/شروع App Pool با `appcmd`/`WebAdministration`.
- اجرای واقعی با **Windows PowerShell 5.1** (تست ما روی pwsh 7 با فرمان‌های شبیه‌سازی‌شده بود).
- `BACKUP DATABASE`/`RESTORE DATABASE` روی نمونهٔ واقعی SQL Server (sqlcmd و I/O واقعی).

## فرض‌ها

- نام App Pool از `package-info.json` (`appPoolName`) خوانده می‌شود؛ پیش‌فرض `TotallCollection`.
- دروازهٔ لایسنس پیش‌فرض از `/api/health` می‌پرسد؛ اگر سرور بالا نباشد «نامعلوم» است و **ادامه** می‌دهد
  (نصب تازه/سرور خاموش نباید قفل شود). حالت‌های `Sql`/`File` برای نصب‌های بدون API در دسترس است.
- پشتیبان دیتابیس با `WITH INIT, NOFORMAT, CHECKSUM` و بدون `COMPRESSION` گرفته می‌شود تا با نسخه‌های
  قدیمی‌تر SQL Server هم باز شود.
- در حالت `DbProvider=File` (فقط تست/SQLite) پشتیبان = کپی فایل دیتابیس.
