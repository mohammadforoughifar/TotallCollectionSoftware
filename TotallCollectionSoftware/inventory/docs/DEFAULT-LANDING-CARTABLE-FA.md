# صفحهٔ آغازین نرم‌افزار: «کارتابل من» (نه داشبورد)

**تاریخ:** ۱۴۰۵/۰۸/۲۴ · **ماژول:** `Inventory.Client` (Blazor WASM) · **بدون تغییر API و بدون مایگریشن**

---

## ۱) رفتار پیش از این و پس از این

| موقعیت | قبل | بعد |
|---|---|---|
| باز شدن نرم‌افزار (ورود موفق) | داشبورد (`/`) | **کارتابل من** (`/`) |
| داشبورد | `/` | `/dashboard` (از منو: سامانه فروشگاهی ← داشبورد ← داشبورد مالی) |
| کاربر معرف (referrer) | داشبورد پورسانت | بدون تغییر (همان داشبورد) |
| کاربر بدون مجوز کارتابل | داشبورد | بدون تغییر (همان داشبورد) |

## ۲) چه چیزی در کد عوض شد

| فایل | تغییر |
|---|---|
| `Pages/Panel/MyDashboard.razor` | مسیر `@page "/"` به `@page "/dashboard"` تغییر کرد (محتوای داشبورد دست‌نخورده). |
| `Pages/Panel/RootLanding.razor` | **جدید:** صاحب مسیر `/`. اگر کاربر مجوز `MyCartable.View` داشته باشد `<Cartable />` و در غیر این صورت `<MyDashboard />` را رندر می‌کند. |
| `Layout/NavMenu.razor` | «کارتابل من» به تبِ خانه (`href=""`) وصل شد؛ «داشبورد مالی» به `dashboard`. |
| `Layout/MainLayout.razor` | آیتم اول نوار پایین در موبایل: «کارتابل» با آیکن کارتابل (برای معرف بدون تغییر). |
| `Services/TabService.cs` | عنوان تبِ ریشه = «کارتابل من»؛ نگاشت تازهٔ `dashboard ⇒ داشبورد`؛ عنوان تبِ خانه از نسخهٔ ذخیره‌شده در localStorage بازنویسی نمی‌شود. |
| `App.razor` · `Shared/ShopSectionGate.razor` | برچسب دکمهٔ بازگشت: «بازگشت به کارتابل» / «بازگشت به صفحهٔ اصلی». |

## ۳) چند تصمیم که عمداً این‌طور گرفته شد

1. **بدون ریدایرکت:** محتوای کارتابل در خودِ مسیر `/` رندر می‌شود. اگر ریدایرکت می‌کردیم،
   سیستم تب‌ها یک تبِ خانهٔ خالی و یک تبِ کارتابل می‌ساخت (تب تکراری + تبِ سنجاقِ بی‌محتوا).
2. **ملاک دسترسی = همان گارد مسیر:** شرط رندر کارتابل `Auth.Has("MyCartable.View")` است؛
   دقیقاً همان پرمیشنی که `RouteGuards` در `MainLayout` برای مسیر `cartable` می‌خواهد،
   تا صفحهٔ ریشه هیچ‌وقت از گارد عبور نکند.
3. **داشبورد حذف نشد:** فقط آدرسش عوض شد؛ همهٔ لینک‌ها و میان‌برهای قبلی به `/dashboard` منتقل شدند.

## ۴) آزمون

```bash
# بیلد کلاینت (Razor + C#)
dotnet build inventory/src/Inventory.Client/Inventory.Client.csproj -c Release

# اگر حافظهٔ ماشین کم بود (csc با کد ۱۳۷ کشته می‌شود):
dotnet build inventory/src/Inventory.Client/Inventory.Client.csproj -c Release \
  -m:1 -p:UseSharedCompilation=false -p:RunAnalyzers=false -p:EnableNETAnalyzers=false
```

نتیجهٔ اجرا در این تغییر: **۰ خطا** (۴۴ هشدارِ از قبل موجود، بدون هشدار تازه).

## ۵) چک‌لیست دستی پس از انتشار

- [ ] از منو: سامانه فروشگاهی ← داشبورد ← داشبورد مالی ⇒ `/dashboard` باز می‌شود.
- [ ] ورود با کاربر معرف (referrer) ⇒ همان داشبورد پورسانت (بدون تغییر).
- [ ] موبایل: آیتم اول نوار پایین «کارتابل» است.
