# نام‌های نمایشی ماژول‌ها

نام‌های جدید به ترتیب فهرست تأییدشده:

| بخش | نام نمایشی |
|---|---|
| اتوماسیون اداری | اتوماسیون اداری توکا |
| دستور کار | دستورکار رایکا |
| ERP | ERP فیکا |
| پیام‌رسان سازمانی | پیام رسان میها |
| سامانه فروشگاهی | فروشگاهی کایر |
| ماژول مودیان | مودیان تیسا |

این تغییر شامل عنوان گروه‌های منو، عنوان‌های اصلی صفحه/تب، برچسب نقش‌ها و دسترسی‌ها، راهنمای فروشگاه و نام نمایشی ماژول‌های متناظر در کاتالوگ لایسنس است. ترتیب گروه‌های موجود و منطق نمایش/دسترسی آن‌ها تغییر نکرده است.

کدهای داخلی مانند `workorders`، `letters`، `chat` و `moadian`، کلیدهای RBAC، routeها، API، منطق اعتبارسنجی لایسنس و نام‌های ذخیره‌شده در داده‌های قدیمی تغییر نکرده‌اند. مهاجرت دیتابیس لازم نیست. برای مثال مقدار ذخیره‌شوندهٔ گزینهٔ منبع نامه همچنان `اتوماسیون اداری` است و فقط متن گزینه نام جدید را نشان می‌دهد.

اشاره به سرویس بیرونی/قانونی «سامانه مودیان» در توضیحات ارسال صورتحساب عمداً با نام محصول جایگزین نشده است. واژهٔ «دستور کار» در دکمهٔ ساخت رکورد و شرح وظیفه نیز نام یک موجودیت است و به نام محصول تبدیل نشده است.

## بررسی

```sh
python -m unittest discover -s tests/ModuleBranding -v
dotnet build src/Inventory.Client/Inventory.Client.csproj -c Release -p:WasmEnableWebcil=false
dotnet build src/Inventory.Licensing/Inventory.Licensing.csproj -c Release
```

گزینهٔ Webcil فقط در فرمان ساخت برای سازگاری محیط Linux است؛ SDK/csproj برای این راهکار تغییر نکرده‌اند. آزمون‌ها نام‌های منو، عنوان‌ها، برچسب‌های نقش، کدها و مسیرهای پایدار و حفظ مقدار قدیمی فیلد داده را کنترل می‌کنند. این بررسی معادل آزمون تعاملی مرورگر یا اتصال به SQL مقصد نیست.

خروجی ZIPهای قبلی با این commit بازسازی نشده‌اند؛ برای مشاهدهٔ نام‌های تازه روی سرور باید پس از این تغییر، پابلیش جدید ساخته و نصب شود.
