# تنظیمات تخفیف فروش ویزیتوری

در «سامانه فروشگاهی ← تنظیمات فروشگاه»، علاوه بر اطلاعات چاپ، سقف تخفیف هر کاربر فعال با مجوز `SalesVisit.Create` برای شرکت فعال تنظیم می‌شود. کاربر باید به شرکت دسترسی داشته باشد (یا در داده‌های قدیمی شرکت او در SystemUsers ثبت شده باشد). مشاهده و تغییر به‌ترتیب از مجوزهای موجود `Shop.PrintSettings.View` و `Shop.PrintSettings.Manage` استفاده می‌کند. بعد از انتخاب شرکت برای هر ویزیتور سقف را جداگانه ذخیره کنید.

سقف‌ها بر اساس شناسهٔ کاربر و شرکت نگهداری می‌شوند، نه معرف. مقدار پیش‌فرض صفر است، یعنی هیچ تخفیفی مجاز نیست. مقادیر قدیمیِ معرف به دلیل ابهام در انتساب به کاربران و شرکت‌ها خودکار منتقل نمی‌شوند؛ پس از استقرار باید برای هر ویزیتور و شرکت بازبینی و تنظیم شوند. اطلاعات قدیمی معرف حذف نمی‌شود ولی دیگر برای این محدودیت به کار نمی‌رود. سقف شامل تخفیف مبلغی و درصدی است و سرور آن را هنگام ذخیره و ارسال بررسی می‌کند. مدیر دارای مجوز تأیید و مدیر سامانه محدودیت سقف ندارند.

در ثبت سفارش جدید نام کاربر ثبت‌کننده ثبت می‌شود؛ اتصال اختیاری معرف برای کاربردهای پورسانت همچنان جداگانه حفظ می‌شود. سفارش‌های قدیمی بازنویسی نمی‌شوند و «سفارش‌های من» بر اساس شناسهٔ ثبت‌کننده فیلتر می‌شود. قیمت ویزیتور از قیمت جاری فروش در سرور تعیین می‌شود. اگر قیمت پیش‌نویس هنگام ارسال تغییر کرده باشد، لازم است سفارش باز و مجدداً ذخیره شود.

جدول جدید از طریق مایگریشن SQL Server و مسیر خودتعمیر راه‌اندازی برای SQL Server و SQLite ساخته می‌شود. پیش از انتشار از پایگاه داده پشتیبان تهیه و مهاجرت، مجوزها و گردش کار چندشرکتی در محیط آزمایشی بررسی شود.
