# کارتابل نامهٔ صادره — «خوانده‌نشده» درست کار کند

## مشکل ۱: شمارنده با باز کردن نامه همان لحظه آپدیت نمی‌شد
در `OutgoingLetterCartable.LoadDetailAsync` عملیات «خوانده شد» فقط داخل این شرط اجرا می‌شد:

```csharp
if (selected?.MyErja is { IsRead: false } my) { ... stats = await GetStatsAsync(); }
```

یعنی اگر کاربر از مسیر «امضاکننده» نامه را باز می‌کرد (بدون ارجاع)، هیچ‌چیز علامت‌گذاری و
هیچ شمارنده‌ای تازه نمی‌شد؛ و در حالت عادی هم فقط `stats` تازه می‌شد، خود ردیف فهرست دست‌نخورده
می‌ماند.

اصلاح: هر بار باز شدن نامه:
1. `POST api/outgoing-letters/{id}/read` صدا زده می‌شود؛
2. `IsRead` روی همهٔ ردیف‌های همان نامه در فهرست محلی `true` می‌شود؛
3. `stats` از سرور دوباره خوانده و `StateHasChanged()` اجرا می‌شود.

نتیجه: بج «دریافتی» و چیپ «خوانده‌نشده» همان لحظه کم می‌شوند و اگر فیلتر روی «خوانده‌نشده»
باشد آن ردیف بلافاصله از فهرست کنار می‌رود (بدون رفرش صفحه).

## مشکل ۲: امضاکننده تا امضا نمی‌کرد «خوانده‌نشده» می‌ماند
ریشه در سرور بود:

```csharp
IsRead = s.IsSigned,                        // نمایش ردیف
qSign = qSign.Where(s => !s.IsSigned);      // فیلتر «خوانده‌نشده»
```

یعنی «خوانده‌شدن» مساوی «امضا کردن» گرفته می‌شد. حالا وضعیت خوانده‌شدن **مستقل** شد:

| تغییر | توضیح |
|---|---|
| ستون‌های جدید | `OutgoingLetterSigners.IsRead`, `DateRead` با خودتعمیر اسکیما `OutgoingSignerReadSchemaV1` (SQLite + SQL Server، idempotent) |
| فیلتر | `!s.IsRead && !s.IsSigned` (نامهٔ امضاشده هم خوانده‌شده حساب می‌شود) |
| نمایش | `IsRead = s.IsRead \|\| s.IsSigned` |
| شمارنده | `InboxUnread` = ارجاع‌های نخوانده + ردیف‌های امضای نخوانده |
| endpoint جدید | `POST api/outgoing-letters/{id}/read` → همهٔ ارجاع‌های نخواندهٔ همین کاربر برای آن نامه + ردیف امضای او را «خوانده» می‌کند |
| صفحهٔ نمایش کامل | `OutgoingLetterView` هم هنگام باز شدن، همان endpoint را صدا می‌زند |

`SigningInboxAsync(unsignedOnly)`, بج نارنجی «امضا» و منطق امضا دست‌نخورده‌اند؛ «خوانده‌نشده» و
«امضانشده» دو مفهوم جدا هستند.

## تست
1. با کاربر امضاکننده (بدون ارجاع) وارد «کارتابل نامه صادره» → «دریافتی» → چیپ «خوانده‌نشده».
2. یک نامه را باز کنید: همان لحظه عدد چیپ/بج یکی کم شود و ردیف از فهرست فیلترشده حذف شود.
3. امضا نکنید، صفحه را رفرش کنید: نامه دیگر در «خوانده‌نشده» نباشد، اما در بج نارنجی «امضا»
   (امضانشده‌ها) بماند.
4. امضا کنید → از بج نارنجی هم خارج شود.
5. با کاربر دارای ارجاع: باز کردن نامه → ارجاع خوانده شود و شمارنده کم شود.
