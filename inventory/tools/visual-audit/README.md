# راستی‌آزمایی بصری و ممیزی خوانایی/چیدمان در مرورگر واقعی

این ابزار با **Chromium واقعی** (Playwright) وارد سامانه می‌شود، فرم‌های آرشیو اسناد و مدارک را
باز می‌کند و دو کار انجام می‌دهد:

1. **اسکرین‌شات** در دو اندازهٔ دسکتاپ (۱۴۴۰×۹۰۰) و موبایل (۳۹۰×۸۴۴): صفحهٔ آرشیو، مودال پوشه جدید
   (با ویرایشگر دسترسی)، فرم «مدرک جدید» (باز/بازشو/اسکرول‌شده) و مودال برچسب‌ها (با رنگ‌های
   روشن و میانهٔ ساخته‌شده).
2. **ممیزی خودکار** روی همهٔ گره‌های متنیِ دیده‌شونده:
   - نسبت کنتراست WCAG متن/پس‌زمینه (آستانهٔ ۴.۵، برای متن درشت ۳) — شامل رنگ‌های ارثی و
     کلاس‌های بوت‌استرپ که ممیزی ایستای CSS نمی‌بیند؛
   - بیرون‌زدگی المان‌ها از ویوپورت و سرریز افقی؛
   - چیدمان RTL چک‌باکس‌ها (ورودی باید هم‌سطروِ راستِ برچسب باشد)؛
   - وضعیت مودال بلند: `max-height`، اسکرول‌پذیری بدنه و دیده‌شدن فوتر؛
   - فونت‌های زیر ۱۱.۵px (برای فارسی ناخوانا هستند).

خروجی: `…/shots/*.png` + `report.json` + `run.log`.

## اجرا

```bash
# ۱) وابستگی‌ها (یک‌بار)
npm init -y && npm i playwright && npx playwright install chromium

# ۲) API با دیتابیس موقت Sqlite
cd inventory/src/Inventory.Api && dotnet run --no-launch-profile --urls http://0.0.0.0:5100 \
  -- Database:Provider=Sqlite "ConnectionStrings:Default=Data Source=/tmp/dev.db" Database:SeedDemoData=true

# ۳) کلاینت
cd ../Inventory.Client && dotnet run --no-launch-profile --urls http://0.0.0.0:5210

# ۴) ممیزی (کاربر پیش‌فرض اولین اجرا: admin / admin)
node inventory/tools/visual-audit/audit.js
```

> نکته: در اولین اجرا با دادهٔ نمونه، کاربر `admin` ساخته نمی‌شود (چون کاربران دمو وجود دارند)؛
> یا بدون `SeedDemoData` اجرا کنید یا یک کاربر Admin بسازید.
