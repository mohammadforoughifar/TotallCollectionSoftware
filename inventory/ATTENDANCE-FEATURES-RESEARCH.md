## وضعیت فعلی سیستم شما (مقایسه سریع)
**داریم (✔):** چندپانچ روزانه (۵ جفت) • شیفت + تاخیر مجاز • کسری/تاخیر/تعجیل • مرخصی روزانه/ساعتی + ماموریت ساعتی (شامل ثبت عقب‌النصر و به‌جای کاربر) • تعطیلات شرکتی • تقویم شمسی • بلادرنگ • RBAC • گزارش + CSV

**اولویت پیشنهادی اجرا در سیستم شما:**
1. ✔✔ **#1 کشف پانچ فراموش‌شده + تایید اجباری** — بیشترین اثر عملیاتی با کمترین وابستگی سخت‌افزاری
2. **#2 هشدار لحظه‌ای تاخیر** — تقریباً آماده (داده هست؛ فقط اعلان)
3. **#11 تقویم تیمی مرخصی** — داده موجود است؛ فقط UI
4. **#12/#13 موجودی + انباشت + Carry-over** — پایه‌ی قوانین مرخصی
5. **#5 GPS + ژئوفنس** — نیازمند اپ/مرورگر با دسترسی موقعیت
6. **#30/#31 پیامک + ربات** — برای پذیرش پرسنل
