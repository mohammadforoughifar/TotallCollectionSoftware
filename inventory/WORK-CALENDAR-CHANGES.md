# 🗓️ تقویم کاری سالانه + تعطیلات رسمی + تنظیمات — فهرست تغییرات

خلاصه‌ی اعمال‌شده روی پروژه‌ی `inventory` (سامانه جامع انبار و فروش):

## ✨ امکانات جدید

1. **نمای سالانه (۱۲ ماه)** — صفحه‌ی «تقویم کاری» (`/work-calendar`) حالا کل ۱۲ ماه سال شمسی را در یک صفحه نشان می‌دهد؛ کلیک روی هر روز، ویرایشگر همان روز را باز می‌کند (روز کاری/تعطیل، ساعت شروع/پایان با پشتیبانی شیفت شب، حالت‌های اضافه‌کاری، یادداشت).
2. **تعطیلات رسمی کشور** — تب «تعطیلات رسمی»:
   - دریافت گروهی تعطیلات رسمی هر سال از **کاتالوگ داخلی**؛
   - تعطیلات ثابت شمسی (نوروز، ۱۲ و ۱۳ فروردین، ۱۴ و ۱۵ خرداد، ۲۲ بهمن، ۲۹ اسفند) برای **هر سالی** تولید می‌شود؛
   - تعطیلات قمری **۱۴۰۴ (۲۷ مورد)** و **۱۴۰۵ (۲۶ مورد)** مطابق تقویم رسمی ابلاغی؛
   - افزودن/حذف دستی + گزینه‌ی جایگزینی برای به‌روزرسانی؛
   - در اولین اجرا، تعطیلات رسمی سال جاری به‌طور خودکار وارد دیتابیس می‌شود؛
   - تعطیلات رسمی به‌طور خودکار در **ارزیابی حضور و غیاب** (بدون کسری) و همه‌ی گزارش‌ها اعمال می‌شوند.
3. **تنظیمات تقویم** — تب «تنظیمات»:
   - ساعت کاری پیش‌فرض شروع/پایان (شیفت شب = پایان قبل از شروع) و تاخیر مجاز؛
   - **روزهای تعطیل هفته** (هر ترکیبی از شنبه تا جمعه — مثلاً «پنجشنبه و جمعه»)؛
   - کلید «اعمال خودکار تعطیلات رسمی کشور»؛
   - تنظیمات مبنای قاعده‌ی پیش‌فرض ارزیابی ورود/خروج پرسنل است.
4. **اکشن‌های گروهی سالانه** — اعمال ساعت به همه‌ی روزهای کاری سال، تعطیل‌کردن روزهای تعطیل هفته، کپی قوانین از سال قبل، پاک‌کردن قوانین سال، و ذخیره‌ی کل سال با یک درخواست.
5. **آمار زنده** — روزهای کاری، جمع ساعات کاری سال/ماه، تعداد تعطیلات رسمی/شرکتی و قوانین سفارشی.

## 🔌 APIهای جدید (پیشوند `/api/Attendance`)

| متد | مسیر | توضیح |
|---|---|---|
| GET | `calendar-year?jy=` | تقویم کامل ۱۲ ماه سال + آمار + تنظیمات |
| GET / PUT | `calendar-settings` | خواندن/ذخیره‌ی تنظیمات تقویم کاری |
| GET | `official-holidays?jy=` | تعطیلات رسمی یک سال شمسی |
| POST | `official-holidays` | افزودن/اصلاح دستی یک تعطیل رسمی |
| POST | `official-holidays/import` | ورود گروهی از کاتالوگ `{ year, replace }` |
| DELETE | `official-holidays/{id}` | حذف تعطیل رسمی |

## 🚀 اجرا

```powershell
# ویندوز — فقط مثل قبل:
cd inventory
.\deploy-single.ps1      # (در این نسخه wwwroot از قبل پابلیش شده)
cd src\Inventory.Api
dotnet run               # مایگریشن‌ها خودکار اعمال می‌شوند
```

- **SQL Server**: در اجرای بعدی، `Database.Migrate()` مایگریشن جدید را خودکار اعمال می‌کند.
- **SQLite (توسعه)**: `Database__Provider=Sqlite` + `ConnectionStrings__Default="Data Source=inventory.db"` — ستون‌ها/جدول‌های جدید به‌صورت خودتعمیر اضافه می‌شوند.
- ورود پیش‌فرض: `admin / admin`
