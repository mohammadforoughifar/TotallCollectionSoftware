=====================================================================
 نسخه‌ی جدید — تقویم کاری (لیستی + شیفت شب + اضافه‌کاری)
=====================================================================

این ارور که قبلاً می‌دادید:
  «ساعت پایان روز 1405/06/01 باید بعد از ساعت شروع باشد.»
از نسخه‌ی قدیمی است. در این نسخه هیچ‌جا چنین بررسی وجود ندارد و
اگر پایان را قبل از شروع بگذارید (مثلاً 22:00 تا 06:00) یعنی
شیفت شب است و به‌جای خطا، نشانِ سبزِ «شیفت شب» را می‌بینید.

---------------------------------------------------------------------
مهم‌ترین نکته: نسخه‌ی قدیمی هنوز در حال اجراست!
---------------------------------------------------------------------
اگر فقط فایل‌ها را عوض کنید ولی برنامه‌ی قدیمی را نبندید، باز هم
همان نسخه‌ی قدیمی اجرا می‌شود و همان ارور را می‌بینید.

=====================================================================
فقط این ۴ قدم را انجام دهید (ویندوز):
=====================================================================

قدم ۱) برنامه‌ی قدیمی را کامل ببندید
    - اگر در یک پنجره‌ی سیاه (کنسول) اجرا شده، آن پنجره را ببندید.
    - اگر نمی‌دانید اجراست یا نه: Task Manager → در لیست
      «dotnet.exe» یا «Inventory.Api» را پیدا و End Task کنید.

قدم ۲) این زیپ را روی همین فولدرِ فعلیِ برنامه extract کنید
    - روی فایل راست‌کلیک → «Extract here» (یا 7-Zip → Extract Here).
    - اجازه دهید همه‌ی فایل‌های قدیمی با جدید «جایگزین» شوند
      (سؤال Replace → Yes to All).

قدم ۳) برنامه را اجرا کنید
    - روش الف (همان روش همیشه‌ای شما): همان‌طور که قبلاً اجرا
      می‌کردید (مثلاً RUN.ps1 یا deploy-single.ps1 و بعد dotnet run).
    - روش ب: در Explorer داخل پوشه‌ی src\Inventory.Api بروید،
      نوار بالا را کلیک کنید و بنویسید:  cmd
      بعد بنویسید:  dotnet run
    - صبر کنید تا نوشته شود:  Now listening on: http://localhost:5100

قدم ۴) مرورگر را با رفرش کامل باز کنید
    - آدرس را باز کنید و حتماً Ctrl + F5 بزنید
      (کلاینت قدیمی در کشِ مرورگر می‌ماند؛ بدون رفرش کامل
      فرمِ قدیمیِ ۷ ستونه را نشان می‌دهد).

---------------------------------------------------------------------
چطور مطمئن شوید نسخه‌ی جدید اجرا شده؟
---------------------------------------------------------------------
    1) صفحه‌ی «تقویم کاری» دیگر گریدِ ۷ ستونه نیست؛
       یک لیست است که هر روز یک ردیف کامل دارد.
    2) روی هر روز دکمه‌های «روز کاری / تعطیل» هست.
    3) برای اضافه‌کاری ۴ گزینه دارد: بدون / بازه زمانی (از-تا) /
       کلِ روز اضافه‌کار / سقف ساعتی.
    4) اگر ساعت پایان را قبل از شروع بگذارید (مثلاً 22:00 تا 06:00)،
       نشانِ سبزِ «شیفت شب — از نیمه‌شب عبور می‌کند ✓» می‌بینید.
    5) پایین صفحه بخش «منطق ارزیابی» به ۴ کارت تفکیک‌شده تبدیل شده.

اگر بعد از قدم ۴ هنوز گریدِ ۷ ستونه یا همان ارور را دیدید، یعنی
قدم ۱ یا قدم ۲ کامل انجام نشده (نسخه‌ی قدیمی هنوز اجراست یا
فایل‌ها جایگزین نشده‌اند).

---------------------------------------------------------------------
دیتابیس (خودکار — کاری از شما نیست):
---------------------------------------------------------------------
    - SQL Server: مایگریشنِ جدید (ستون‌های اضافه‌کاریِ تقویم)
      با اولین اجرا به‌صورت خودکار اعمال می‌شود.
    - SQLite: اگر دیتابیسِ قدیمی (inventory.db) داشته باشید،
      ستون‌های کم‌شده خودکار اضافه می‌شوند.
    ⚠ دیتابیس را حذف نکنید؛ داده‌هایتان حفظ می‌شود.

---------------------------------------------------------------------
خلاصه‌ی ۶ مورد درخواستی:
---------------------------------------------------------------------
  ۱. ارور ساعت پایان ← رفع شد (شیفت شب مجاز و پشتیبانی کامل شده؛
     خروج صبحِ بعد از نیمه‌شب هم درست ثبت می‌شود).
  ۲. رسپانسو ← موبایل تک‌ستونه، دسکتاپ ردیفی.
  ۳. تعطیل کردن روز ← دکمه‌ی «روز کاری/تعطیل» روی هر روز +
     «تعطیل کردن همه‌ی جمعه‌ها».
  ۴. منطق ارزیابی ← بخش تاشو با ۴ کارت تفکیک‌شده + مثال عددی.
  ۵. لیستی ← گرید حذف شد، لیست ردیفی شد.
  ۶. اضافه‌کاری ← بازه‌ی زمانی (از-تا، حتی عبور از نیمه‌شب)
     یا کلِ روز یا سقف ساعتی؛ برای روز کاری و تعطیل.
