# پیش‌نمایش نوار فیلتر «طرح تعویض» (فقط نمایشی)

این یک نمونهٔ **ایزوله و بدون اتصال به سرور** از نوار فیلتر فشردهٔ صفحهٔ
`/repairs` → تب «طرح تعویض» است. داده‌ها نمونه‌اند و هیچ API، دیتابیس یا تنظیمی
تغییر نمی‌کند.

```
python3 -m http.server 8082 --bind 0.0.0.0   # از همین پوشه
```

## چه چیزی نشان می‌دهد

- یک ردیف باریک: **جستجوی زنده** + **وضعیت** + **بازهٔ تاریخ پذیرش در یک گروه**،
  به‌همراه شمارش نتایج و «پاک کردن فیلترها» در همان ردیف.
- فیلترها زنده اعمال می‌شوند؛ دکمهٔ «اعمال فیلتر» حذف شده است.
- **بازه‌های سریع ۷ / ۳۰ / ۹۰ روز** کنار فیلدهای تاریخ (کلیک دوباره = برداشتن بازه)؛
  این‌ها فیلتر جدیدی به API اضافه نمی‌کنند و فقط پارامتر `from` را پر می‌کنند.
- فیلترهای فعال به‌صورت **چیپ قابل حذف** زیر نوار نمایش داده می‌شوند.
- هنگام تایپ، جدول پاک نمی‌شود و فقط کم‌رنگ می‌شود (بدون پرش/لرزش).

منبع اصلی: `inventory/src/Inventory.Client/Pages/Repairs/TradeInTab.razor`
(همان کلاس‌های `ti-*`). فونت‌ها و استایل‌ها از `Inventory.Client/wwwroot` کپی شده‌اند.
