# آزمون سازنده‌های چاپ — PrintProbe

این پروژه، **همان فایل‌های کدِ تولید** سازنده‌های چاپ را کامپایل می‌کند و بدون نیاز به مرورگر،
HTML نهایی هر سند را می‌سازد و با بررسی‌های کلیدواژه‌ای/عددی می‌سنجد:

| سازندهٔ چاپ | کجا استفاده می‌شود |
|---|---|
| `SaleInvoicePrint` | چاپ سند **فروش** و **خرید** در صفحهٔ «فروش/خرید» (`/orders/sale`)، دکمهٔ «ثبت و چاپ» فرم، و فاکتور فروشِ ساخته‌شده از تعمیرات |
| `FacInvoicePrint` | چاپ **فاکتور** در ماژول فاکتورها (فروش / خرید / برگشت از فروش / برگشت از خرید) |
| `RepairDeliveryReceiptPrint` | چاپ **فیش تحویل دستگاه** در ماژول عملیات ← تعمیرات (شامل متن گارانتی ۱۰ روز) |

## اجرا

```bash
dotnet run --project inventory/tests/PrintProbe/PrintProbe.csproj -c Release
```

خروجی: فهرست بررسی‌های OK/FAIL و ذخیرهٔ سندهای نمونه در پوشهٔ خروجی پروژه:

```
bin/Release/net8.0/out-sale.html        ← فاکتور فروش صفحهٔ «فروش»
bin/Release/net8.0/out-purchase.html    ← رسید خرید
bin/Release/net8.0/out-fac.html         ← فاکتور ماژول فاکتورها (A4)
bin/Release/net8.0/out-fac-a5.html      ← همان فاکتور در کاغذ A5
bin/Release/net8.0/out-receipt.html     ← فیش تحویل تعمیرات
```

کد خروج `0` یعنی همهٔ بررسی‌ها موفق است؛ هر تغییر در متن‌ها/مبالغ چاپ که چیزی را خراب کند،
همین‌جا با خطا دیده می‌شود (قبل از رسیدن به سرور مشتری).

## نمونه بررسی‌ها

- جمع‌های سند: `۱۴,۷۰۰,۰۰۰` (فاکتور فروش) و `۲۹,۲۵۰,۰۰۰` (فاکتور با تخفیف/مالیات/حمل) و ماندهٔ `۲۴,۲۵۰,۰۰۰`
- وجود ستون‌های تخفیف/مالیات فقط وقتی مقدار دارند
- حالت کاغذ A5 (`A5 portrait` و عرض `134mm`)
- متن گارانتی فیش تحویل: «۱۰ روز مهلت تست» موجود و «۳۰ روز مهلت تست» حذف‌شده
- وجود سربرگ شرکت، شماره حساب، کادر امضا و جای‌گذاری مسیر فونت (`__FONT_BASE__`) برای چاپ در iframe
